# Create 26.2 adaptation — external assets edition

Adaptation version: **0.81**

Compatibility target:

- Minecraft: **26.2**
- NeoForge: **26.2.0.57 or newer in the 26.2 series**
- Tested with NeoForge: **26.2.0.57, 26.2.0.58, and 26.2.0.59**
- Official asset source: **Create 6.0.10 for Minecraft 1.21.1**

The public jar does not contain upstream Create textures, models, sounds,
fonts, or other copyrighted client artwork. The upstream Create license marks
those original assets as All Rights Reserved, so this adaptation does not
redistribute them. It contains only a small JSON compatibility layer authored
or generated by this port for Minecraft 26.2's resource format.
This includes JSON-only item definitions, equipment declarations, and atlas
routing rules needed by Minecraft 26.2's separate block and item atlases.

Download the official jar from the [official Create CurseForge page](https://www.curseforge.com/minecraft/mc-mods/create/files/all?page=1&pageSize=20&version=1.21.1),
then put it in `<game directory>/create_original/`. Do not put the old jar in
`mods`: NeoForge would otherwise find two mods with the same `create` id.

The adaptation mounts the player-supplied jar only as a client resource pack.
Its classes are not added to the mod classpath and are never executed. A
dedicated server does not need the original asset jar.

The adapted Flywheel 1.0.6, Ponder, Catnip, and Registrate libraries are
embedded as NeoForge Jar-in-Jar dependencies. Flywheel, Ponder, and Catnip are
MIT licensed and their license notices are included. The player installs only
the adaptation jar; no separate library files are required.
