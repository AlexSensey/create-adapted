# Security Policy

## Supported versions

Only the newest published Create: Adapted release is supported. This early
adaptation targets Minecraft 26.2 and NeoForge 26.2.0.18-beta.

## Reporting a vulnerability

Please report security issues privately through
[GitHub Security Advisories](https://github.com/AlexSensey/create-adapted/security/advisories/new).
Do not publish exploitable details in a regular issue before a fix is
available.
